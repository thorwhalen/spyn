spyn.ppi.pot

Potentials: probability/likelihood tables with algebraic operators.

The Pot class represents discrete probability tables as DataFrames with a ‘pval’ column and uses operator overloading for probabilistic inference:

  • * factor product

  • / normalization, conditioning, or factor division

  • [] marginalization (list/str) or slicing (dict)

  • >> projection (marginalization)

>>> p = Pot({'A': [0, 0, 1, 1], 'B': [0, 1, 0, 1], 'pval': [2, 4, 5, 9]})
>>> p['A']  # marginalize to A
     pval
A
0       6
1      14
>>> (p / []).round(2)  # normalize
        pval
A B
0 0     0.10
  1     0.20
1 0     0.25
  1     0.45
class spyn.ppi.pot.Pot(data: Pot | float | int | DataFrame | dict | None = None)[source]

A discrete potential (probability/likelihood table).

The core data structure is a pandas DataFrame (self.tb) with variable columns and a mandatory pval column holding the values.

>>> p = Pot({'A': [0, 1], 'B': [0, 1], 'pval': [0.3, 0.7]})
>>> p.vars
['A', 'B']
>>> p.n
2

assimilate(pot: Pot) → Pot[source]

Bayes rule: multiply by pot, normalize, project back to own vars.

This computes P(X|D) ∝ P(D|X) * P(X), i.e. prior.assimilate(likelihood).

>>> prior = Pot({'H': [0, 1], 'pval': [0.5, 0.5]})
>>> likelihood = Pot({'H': [0, 1], 'pval': [0.2, 0.8]})
>>> posterior = prior.assimilate(likelihood)
>>> posterior.n
2

normalize(var_list: list[str] | str | tuple = ()) → Pot[source]

Normalize the pot with respect to var_list.

If var_list is empty, fully normalizes (divides by total sum). Otherwise, divides by the projection onto var_list (conditional prob).

>>> p = Pot({'A': [0, 1], 'pval': [3, 7]})
>>> p.normalize()  # full normalization
   pval
A
0   0.3
1   0.7
